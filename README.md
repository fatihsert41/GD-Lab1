# GD-Lab1 — Cipher Quest

CENG462 Game Development (Fall 2026–2027), Lab 1. Unity 6.3 LTS (6000.3.25f1), Universal 2D.

Oyuncu 1–1000 arası gizli bir kod tutar; **Codebreaker Fatih** HIGHER / LOWER / CORRECT cevaplarıyla kodu çözmeye çalışır.
Üç sahne (StartMenu → CoreGame → WinScreen), anchor'lı UI, TextMesh Pro, `SceneManager`, `Random.Range`.
